## 📌 Key Features

- **🎨 Modern SaaS Aesthetic:** Clean royal blue design system (`#2563EB`) inspired by Figma community standards, featuring subtle gradients, ambient glowing background spheres, and card hover elevations.
- **🌓 Light / Dark Mode Toggle:** Persistent theme switching with instant color transitions and `localStorage` caching.
- **📱 Fully Responsive:** Optimized fluid experience across mobile (≥360px), tablet, and desktop devices with an animated mobile drawer menu.
- **🔍 Active Scroll-Spy:** Real-time navigation highlighting as sections are scrolled into view.
- **📊 Interactive Project Modals:** Deep-dive case study popups displaying problem statements, data sources, execution methodology, KPI findings, and dashboard lightboxes.
- **⚡ 100/100 Lighthouse Performance:** Pure vanilla HTML5, CSS3, and JavaScript with zero heavy dependencies or framework overhead.
- **📬 Interactive Contact Hub:** Direct email, phone, location, LinkedIn, and GitHub tiles with one-click clipboard copying and direct message forms.

## 💼 Featured Case Studies

### 1. [US Airline Performance Delay Analysis 2015](assets/images/airline_delay_dashboard.jpg)
- **Domain:** Aviation Analytics & Operational Efficiency
- **Tech Stack:** Python, MySQL, Power BI, Pandas, Seaborn
- **Description:** Analyzed 5.8M+ flight records to discover delay bottlenecks across major US carriers. Engineered SQL queries and built an interactive Power BI dashboard tracking on-time performance (OTP), delay attribution (Late Aircraft, Weather, NAS), and airport turnaround delays.

### 2. [Bank Loan Performance & Risk Analysis](assets/images/bank_loan_dashboard.jpg)
- **Domain:** Financial Analytics & Credit Risk Modeling
- **Tech Stack:** SQL, Power BI, Excel, Tableau, Financial Modeling
- **Description:** Segmented large loan portfolios into Good vs. Bad loans to assess default probabilities across borrower grades (A through G), debt-to-income (DTI) metrics, and home ownership. Delivered executive dashboards tracking $248M+ in funded loans.

## 💻 Local Setup & Development

To run this project locally without any complex installation:

```bash
# Clone the repository
git clone https://github.com/chinnaobulareddy/Chinna_Data_Analyst_Portfolio.git

# Navigate to the folder
cd Chinna_Data_Analyst_Portfolio

# Start a lightweight local server (Python 3)
python -m http.server 3000
```

Open your browser and navigate to `http://localhost:3000`.
